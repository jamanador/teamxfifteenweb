# Team XFifteen Web

A React-based university event platform for showcasing seminars, workshops, events, speakers, and related event information.

## Tech Stack

- React
- JavaScript / JSX
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Lucide React
- npm

## Project Structure

The project uses a simple and understandable React structure with reusable components, layouts, pages, routing, and frontend data. The images and visual content were collected from different official club pages of East Delta University (EDU) and relevant Google search results for demonstration purposes.
